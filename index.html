Comment fonctionne le code de parrainage

Trois étapes séparent l'ouverture de votre compte du versement de la prime.

1

Démarrez votre souscription

Depuis le site ou l'application BoursoBank, lancez l'ouverture d'un compte (Welcome, Ultim ou Metal selon l'offre en cours).

2

Renseignez le code parrain

Dans le champ « code de parrainage » du parcours de souscription, indiquez VOTRECODE. Il doit être saisi avant la validation finale du dossier, il ne peut pas être ajouté a posteriori.

3

Validez votre compte et recevez la prime

Une fois le compte ouvert et les conditions de l'offre remplies (premier versement, activité carte selon la campagne), la prime filleul est créditée selon le délai annoncé par BoursoBank.

Questions fréquentes

Comment utiliser un code de parrainage BoursoBank ?

Lors de l'ouverture de votre compte sur le site ou l'application BoursoBank, un champ « code de parrainage » apparaît dans le parcours de souscription. Renseignez-y le code du parrain avant de valider votre dossier : il ne peut plus être ajouté une fois le compte ouvert.

Le code fonctionne-t-il si j'ai déjà été client BoursoBank ?

Non, l'offre de parrainage est réservée aux personnes qui n'ont jamais eu de compte chez BoursoBank ou Boursorama Banque. Un ancien client qui rouvre un compte n'est en principe pas éligible à la prime filleul.

Quand la prime de parrainage est-elle versée ?

Le versement intervient une fois le compte validé et les conditions de l'offre en cours remplies, par exemple un premier virement ou une première utilisation de la carte. Les délais et le montant exact varient selon la campagne active : vérifiez-les sur le site officiel avant de souscrire.

Peut-on cumuler le parrainage avec une autre offre de bienvenue ?

Cela dépend des conditions en vigueur au moment de l'ouverture du compte : certaines campagnes remplacent l'offre de bienvenue standard, d'autres s'y ajoutent. Vérifiez les conditions générales de l'offre active avant de souscrire.
